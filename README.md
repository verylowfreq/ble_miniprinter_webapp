# スマホ向け "Mini Printer" の印刷Webアプリ

BLE接続でESC/POSをやりとりする感熱紙プリンターで画像を印刷するWebアプリです。
Web Bluetoothを使用しているため、パソコン上のGoogle Chrome、Android上のGoogle Chromeで動作します。

**[The app on GitHub Pages](https://verylowfreq.github.io/ble_miniprinter_webapp/)**

- Bluetooth LE
- ESC/POS
- Bitmap command "GS v 0"
- 58mm paper (384dot)
